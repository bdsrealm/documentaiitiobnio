Notes for sending packets

Writing

Every page's skeleton becomes a real write through the engine adapter:

// src/engine/bedrockx.js
this.client.write('set_time', { time: 0 })

Failures are caught inside connection.js and printed, not thrown — a malformed payload usually shows up as a stack trace in the bot console and nothing on the wire.

Arrays are the expensive part

A varint count costs 1–5 bytes and can claim a length the body never delivers; the server reads until EOF. An lu32 count is a fixed 4-byte field and is checked more strictly.

Empty strings and empty NBT compounds cost 1 byte per element, which is why packet floods use them.

Direction is not in the schema

The compiled JSON drops !bound. The chips on this page are a curated table for well-known packets; ? means unknown.

For the authoritative per-packet direction, check upstream proto.yml (!bound) or Mojang's generated docs.
